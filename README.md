# 단어 — Koreyscha so'z kartalari

Koreyscha so'zlarni yodlash uchun flash-karta dasturi: so'z yoki rasm kiritiladi, Gemini tarjima va misollar tayyorlaydi, intervalli takrorlash bilan mustahkamlanadi.

- API kaliti va kartalar faqat foydalanuvchining o'z brauzerida (localStorage / IndexedDB) saqlanadi — bu repozitoriyda hech qanday kalit yoki shaxsiy ma'lumot yo'q.
